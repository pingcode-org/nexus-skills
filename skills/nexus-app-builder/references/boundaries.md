# Nexus Skills 职责边界（共用）

按任务选用对应技能；不要为同一问题同时展开无关技能的完整流程。

| Skill                     | 职责                                                                         | 典型请求                                  |
| ------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------- |
| `nexus-app-builder`       | 开发咨询、新建应用、修改已有应用、功能实现、构建验证，以及用户要求的部署分发 | 「增加工作项面板」「Bridge SDK 怎么使用」 |
| `nexus-app-debugger`      | 已有故障的证据收集、定位、修复与复验                                         | 「页面白屏」「API 返回 403」              |
| `nexus-app-reviewer`      | 实现正确性、可维护性、平台用法与发布就绪检查                                 | 「检查这个应用能不能发布」                |
| `nexus-security-reviewer` | 身份、授权、租户隔离、凭据及外部入口安全审查                                 | 「检查 Resolver 是否存在越权」            |

## 执行边界

- builder 根据项目状态选择流程，**不强制**从创建执行到分发。
- 开发过程中出现的普通编译 / 构建错误，由 **builder** 继续修复。
- 用户以排查**已有故障**为目标时，优先使用 **debugger**。
- app-reviewer 可检查明显安全问题，但**不默认**执行完整安全审计。
- security-reviewer 必须给出代码证据、风险成立条件和影响分析。
- **纯咨询**只提供解释与示例，不要求登录、创建项目或部署。

SDK、REST API、manifest 是四个技能共享的知识模块，按任务目的使用。直接查询或修改 PingCode 业务数据 → PingCode CLI。

## 知识原则

**核心知识随包内置；完整平台参考通过官方在线文档按需获取**（见 `docs-online.md`）。

- 常见任务：按条件打开**单个** `references/` / `assets/` 文件（L0/L1）；勿整目录预读。
- 准确 target、scope、API 字段：再上 `https://developer.pingcode.com` / `search_nexus_docs`（L2）。
- 命令与签名：本机 `--help` / 已装 SDK 类型（L3）。
- 运行时只依赖**本包 + 官方在线文档**。
